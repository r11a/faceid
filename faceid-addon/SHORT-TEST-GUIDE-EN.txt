# FaceID 6.9.4 Claude test build

Test build for the disconnected rig (reader and relay disconnected). Recognition and the Access1 connector run as in 6.9.2. Back up the installed app first (Home Assistant backup of the FaceID add-on, downloaded to your PC). Roll back by restoring that backup. Do not deploy to production.

6.9.4 is 6.9.3 with the Settings page back to its single Save button. If you already checked some 6.9.3 steps, only steps 1, 2 and 7 need repeating.

1. Install 6.9.4 over 6.9.3 (or 6.9.2). Do not change any option. Start.
2. Log: the `effective configuration` line must be identical to 6.9.2's (20:46:56). Restart once: identical again.
3. Home Assistant → FaceID → Configuration: your saved options are all still there, now in groups (Connection first, then Engine and stream, ...). Do not save anything.
4. FaceID → Management → Setup, step 3: turn face measurement on for a minute. The picture must update without flashing. The line "measurement only, the door still opens" is shown.
5. Step 6: start the walk test, then go to step 3: the banner shows the camera, time left and "the door will not open". Press "עצור בדיקה" (Stop) in the banner: the banner goes away.
6. Step 6: "ייצוא קובץ הגדרות" (Export settings file) downloads `faceid-site-<date>.json`. Open it in a text editor: no passwords, no rtsp:// address, no Frigate or MQTT address. Then "ייבוא קובץ הגדרות" (Import) with the same file: "אין שינויים" (no changes).
7. FaceID → Settings: one "שמירת כל השינויים" (Save all changes) button at the top, as in 6.9.2; no "שמירת הסעיף" buttons. Change nothing.
8. Walk up once: Access1 opens as usual.
9. Send the full log and a short note of what each step showed.

The labelled unknown-person and replacement passes (including a night round) are still required before any connected-door release.
